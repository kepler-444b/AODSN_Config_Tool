# 奥迪信设置工具使用说明

## 1. 软件简介

奥迪信设置工具用于通过串口配置和管理兼容设备。软件提供设备地址及主机参数设置、面板与扩展设备配置、场景和按键绑定管理、定时任务、网络参数设置，以及串口收发调试功能。

> 本说明依据当前项目版本 v0.4 的界面和实现编写。可用设备类型、串口参数及协议功能需以实际设备固件和硬件为准。

## 2. 启动与连接设备

1. 将电脑连接到设备对应的 USB 转串口适配器或串口接口，并安装好操作系统所需驱动。
2. 启动软件。若提示“程序已经在运行”，说明已有一个实例，请切换到已打开的软件。
3. 在窗口上方选择设备对应的**端口**和**波特率**。软件提供 9600 和 115200 两种选项；请按设备要求选择。
4. 若端口列表未显示设备，点击**刷新**，并检查线缆、驱动及设备供电。
5. 点击**打开**建立串口连接。连接成功后按钮显示为**关闭**，端口和波特率选择控件会锁定。配置或调试前请先打开串口。
6. 完成操作后点击**关闭**断开连接。

串口使用 8 位数据位、无校验、1 位停止位、无流控。若打开失败，请确认端口未被其他程序占用，并检查所选端口及波特率。

## 3. 设备配置

左侧选择**设备配置**进入工程配置页面。配置工程保存在本地 JSON 文件中；设备参数下发是另外的操作，不会因保存 JSON 自动写入设备。

### 3.1 新建、导入与保存

- **新建**：选择 JSON 文件路径后创建空工程，并清空当前面板、扩展设备和场景/绑定数据。新建前请先保存需要保留的内容。
- **导入**：选择已有 JSON 工程文件，加载面板、扩展设备、场景及绑定数据。导入会替换当前页面工程内容；请先保存当前修改。
- **保存**：将当前工程数据写入所选 JSON 文件。也可使用 **Ctrl+S**。
- 软件会记住最近使用的配置文件路径，供下次打开文件对话框时作为默认路径。
- 新建、导入或修改场景/绑定后，建议及时保存。关闭软件时若检测到未保存修改，会提示确认是否仍要退出。

### 3.2 添加面板和扩展设备

- 点击**添加面板**，在弹窗中选择面板类型并设置设备地址；地址不能与当前工程中的其他面板重复。
- 点击**添加扩展**，选择扩展设备类型并填写地址。地址重复时软件会提示重新设置。
- 新增设备会出现在下方配置区域。可根据各设备卡片提供的控件编辑参数；如需移除设备，使用相应卡片上的删除操作。
- 工程支持的面板和扩展设备数量受软件及设备协议限制。若达到上限，新增操作可能不会成功。

### 3.3 场景和按键绑定

1. 点击**创建场景**，按场景编辑界面的提示配置场景及其设备动作。
2. 在面板卡片中为按键选择场景，完成按键与场景的绑定。旋钮类面板可配置其对应绑定。
3. 点击**场景列表**查看已有场景和绑定。列表窗口支持查看、编辑、删除及将场景数据、面板场景或绑定数据下发到设备的相关操作；请按窗口中的按钮及确认提示操作。
4. 如出现绑定重复提示，请先删除冲突的绑定，或为按键选择其他场景。

下发操作需要串口已连接且目标设备在线。按提示等待下发完成；若出现串口错误或设备无响应，检查连接后再重试。

### 3.4 定时任务与时间校准

- 点击**定时任务**打开任务设置窗口。可按窗口提示读取或设置设备定时任务，任务可关联工程中的场景。
- 点击**校准时间**，输入设备时间，格式必须为 `yyyy-MM-dd HH:mm:ss`（例如 `2026-10-20 14:30:00`），确认后软件向设备发送校准命令。取消输入可退出。

## 4. 主机逻辑（地址及主机参数）

左侧选择**主机逻辑**，在**设备选择**中选取与实际硬件相符的设备类型。页面支持灯控面板、4 路可控硅、雷达感应调光主机及毫米波雷达等设备的地址或参数操作。

- 先设置/选择目标设备地址，再点击对应区域的**获取信息**读取设备版本或当前参数。
- 对 4 路可控硅及雷达感应调光主机，可按界面控件调整亮度、死区、渐变时间等参数，再点击**下发配置**写入设备。
- 雷达感应调光主机页面可配置无人、有人及活跃状态亮度，并设置雷达与 PWM/VOL 回路的映射关系；按现场接线和控制需求设置后再下发。
- 页面提供**调试模式**等设备专用操作。设备地址广播/单发等操作可能影响总线上其他设备；执行前确认目标设备和总线环境。
- 毫米波雷达页面支持获取信息、设置地址及下发配置。请按设备型号使用相应控件。

不同设备类型显示的参数和可执行命令可能不同。只修改目标设备支持的项目；下发前核对地址与参数。

## 5. 主机信息（网络设置）

左侧选择**主机信息**打开网络设置页面。

1. 点击**获取信息**读取设备 ID、设备 KEY、IP、网关、MAC、子网掩码（SN）、DNS 和版本等信息。
2. 选择**静态IP**或**动态IP**。静态方式下按网络规划填写 IP、网关、子网掩码和 DNS；设备 ID/KEY 等字段按项目实际要求填写。
3. 点击**下发信息**将页面中的信息发送到设备。看到成功提示后，按网络环境需要重新连接设备。

设置网络参数前请向网络管理员确认地址、网关、掩码和 DNS，避免 IP 冲突或设备失联。MAC 和版本等设备信息通常由设备返回，除非设备或项目要求，不要随意修改。

## 6. 串口调试窗口

从菜单**工具 → 调试窗口**打开调试界面。调试窗口与主界面共用同一串口连接。

- 在输入区域填写要发送的数据，点击**发送**向串口发送。
- 窗口会显示发送（TX）和接收（RX）数据，可用于观察通信情况。
- 点击**清空**清除调试显示内容。

如果串口未打开，发送操作会提示错误。调试窗口发送的数据可能直接控制设备，请确认数据内容和目标连接。

## 7. 常见问题

| 现象 | 建议处理 |
|---|---|
| 端口列表为空 | 连接设备、检查驱动和设备管理器，然后点击**刷新**。 |
| 串口无法打开 | 检查端口是否被占用、设备是否连接，以及端口和波特率是否正确。 |
| 提示波特率错误 | 按提示检查设备要求的波特率，并确认连接的是目标端口。 |
| 获取信息无响应 | 确认串口已打开、设备供电正常、地址正确、设备型号选择正确。 |
| 配置下发失败或设备无变化 | 检查串口连接和设备地址，确认参数适用于该设备，再重新获取信息并下发。 |
| JSON 导入失败 | 确认选择的是本软件支持的 JSON 配置文件，文件未损坏且有读取权限。 |
| 关闭时出现未保存提示 | 选择取消返回并保存；确认不需要保留修改时再选择确定退出。 |
